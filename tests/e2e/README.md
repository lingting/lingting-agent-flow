# tests/e2e

本目录用于存放端到端测试。

当前阶段已实现 CLI 骨架、配置校验、SQLite 数据层、执行节点管理与 SSH 服务探测，
端到端测试尚未编写。执行节点相关流程（新增、设默认、探测、删除）目前由
`internal/cli/host_test.go` 覆盖，SSH 探测使用本地模拟 TCP 服务，不依赖真实服务器。
引入调度器与 Agent 执行后，这里将覆盖：

- 需求提交到任务完成的完整流程。
- 步骤失败后的重试与新会话创建。
- 验证失败后的回退路径。
- 进程异常退出后的任务恢复。

约定：

- 端到端测试必须使用独立的临时工作目录，不得读写用户真实配置与仓库。
- 端到端测试不得依赖真实模型凭据。
