# M0：V1 收口与 V2 设计

> 状态：**completed**（2026-11-02）。
> 本里程碑不修改生产代码。

## 1. 目标

1. 以代码、Schema、测试结构与 CI 配置为依据，核实 V1 最终产品状态。
2. 把 `.steps` 从平铺的 V1 过程记录收口为单一最终状态文档。
3. 建立 V2 文档体系，锁定产品范围、架构、数据模型、工作流、角色与环境管理方向。
4. 明确 V2 非目标，使后续里程碑有可拒绝越界的依据。

## 2. 做了什么

- 删除 V1 过程文档（P1/P2/P3/P4 全部过程文件与阶段路线图），保留可追溯性由 Git 历史承担。
- 新增 [`../V1-final.md`](../V1-final.md)：V1 最终产品状态、核心架构、业务模型、
  执行流程、调度与隔离、持久化与恢复、Web 能力、CI/CD、安全边界、测试结构、
  验收依据与**明确遗留事项**。
- 新增 V2 文档体系：`README.md`、`PRODUCT-SCOPE.md`、`ARCHITECTURE.md`、`DATA-MODEL.md`、
  `WORKFLOW.md`、`ROLE-DESIGN.md`、`ENVIRONMENT-MANAGEMENT.md`、`ROADMAP.md` 与 7 个里程碑文件。
- 核实并记录 8 项代码缺口（G1–G8），作为 M1–M5 的输入。
